# 评测服务企业与成员管理

入口：**应用服务 → 评测服务 → 企业与成员管理**。拥有 `service:admit` 的运营人员可查看已开通企业，编辑名称与启停状态，管理成员及接入方配额。

- 企业停用或删除后，其成员不能登录使用服务，API 网关也拒绝请求。成员停用或删除后，其账号与该成员创建的密钥不可用。
- 删除使用逻辑删除，保留账号身份、历史评测资产、计量与审计归属。已删除成员仍展示在企业成员表和记录筛选中；登录账号不能重用。
- 成员支持编辑昵称、邮箱、电话和账号状态。登录账号保持固定；密码仅存储摘要，支持设置初始密码和重置密码，不提供旧密码明文查询。
- 新建和重置密码时可以生成随机密码，请在保存前妥善记录。密码、密钥和上游凭据不会写入这些管理操作的审计详情。
- 企业列表的“交付数据集”与成员抽屉中的“接入方与配额”使用名称选择，无需手填对象 ID。

**评测操作记录**需要 `service:records`。客户可查看本企业记录；运营人员可在指定企业抽屉中查看该企业记录。可按成员、操作类型和时间筛选，时间展示为北京时间。

记录分为成员操作与 API 访问两类。API 访问按密钥创建成员归属，包含请求路径和 HTTP 状态，不表示一定执行了新的评测。新补充的操作审计从版本上线后开始记录；上线前只能查询已有的审计证据，不补造历史操作。

评测任务列表支持标题和提交成员筛选；任务列表与网关访问审计独立分页。服务端继续使用 TaskService 执行任务，额度按实际用量与在途预占校验。

本次不新增数据库表。权限定义和采集产物已更新；部署时重启后端加载权限配置，并发布前端构建。自定义角色需要按业务需要授予 `service:records`；企业管理继续使用 `service:admit`，客户角色不获得跨企业管理权限。
