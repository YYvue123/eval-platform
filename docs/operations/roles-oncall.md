# 岗位职责与值班响应

版本：2026-09-28-wp16

## 1. 角色

| 角色 | 职责 | 平台权限线索 |
|---|---|---|
| 值班 SRE | 探针、备份、恢复演练、故障注入清理、发布/回滚执行 | `ops:view` `ops:backup` `ops:admit` |
| 运维协调 | 工单分派与闭环、演练留痕、数据授权登记 | `ops:ticket` |
| 评测研究员 | 任务/基准/安全评测；异常提工单 | 业务权限 + `ops:view` |
| 安全对接 | 漏洞受理、证书与通道策略 | 工单 category=`vuln` |
| 运营负责人 | 确认组织事项、许可与对外口径 | 线下签署 + 授权记录 |

## 2. 值班

- 工作时间：工作日本地时区 09:00–18:00（可按单位调整，调整需归档新版本）。
- 交接：下班前检查 `/api/ready`、未关闭 P0 工单、最近一次 backup/admission。
- 响应目标（建议，非对外 SLA 承诺）：P0 15 分钟确认、P1 1 小时、P2 下一工作日。

## 3. 升级

1. 值班无法 30 分钟内恢复 → 通知运维协调与研发 on-call。
2. 涉及租户数据泄漏/越权 → 立即安全对接 + 冻结相关密钥（改 `SECRET_KEY`/吊销会话需变更单）。
3. 生产发布失败 → 按 [WP15-runbook](./WP15-runbook.md) 回滚，并开 `category=incident` 工单。
