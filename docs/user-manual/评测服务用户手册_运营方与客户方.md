# 评测服务用户手册

面向服务运营人员和企业客户成员

版本 1.0　更新日期 2026年10月24日

## 阅读说明

本手册介绍企业开通、成员账号管理、模型接入、评测提交、额度计量与记录查询。运营方按第2章完成客户开通和日常管理；客户方按第3章完成接入与评测；记录查询和异常处理见第4至6章。功能入口以已部署版本和账号实际授权为准。

平台内的完整菜单路径为“应用服务 → 评测服务”，页面地址为 /services。企业客户导航会简化，可能直接显示“评测服务”，无需查找平台管理菜单。运营账号默认打开“企业与成员管理”，客户账号默认打开“需求与交付”。

本手册对应2026年10月24日的评测服务实现。自动化模式会提交真实评测任务；专家模式先生成待确认任务。是否已完成、是否有正式报告、是否已计量和是否已付款，需要分别核对，不能互相替代。

## 1 岗位分工与准备事项

### 1.1 运营方和客户方分别负责什么

| 事项 | 运营方 | 客户方 |
| --- | --- | --- |
| 企业开通与状态管理 | 开通企业，编辑名称，停用或删除企业 | 提供企业和负责人信息，核对账号归属 |
| 成员管理 | 查看成员，添加、编辑、停用、删除及重置密码 | 使用个人账号，可在本企业添加成员；修改自己的密码 |
| 评测数据 | 准备已发布且质检通过的数据集，向客户企业交付 | 从本企业共享数据集中选择 |
| 接入方和额度 | 审批每日及每月额度、请求频率和单价 | 创建接入方，保存密钥，提交额度申请 |
| 模型服务 | 配置允许接入的域名，协助排查接入问题 | 注册本企业模型服务及版本，设置稳定和灰度路由 |
| 任务与报告 | 根据记录协助处理异常和交付核对 | 提交需求，确认专家配置，查看进度，取消任务和下载报告 |
| 操作追踪 | 在指定企业中查询成员操作和 API 访问 | 查询本企业记录，不能访问其他企业 |

客户角色不提供运营方的跨企业管理权限。同一企业共享服务任务与资产，企业内多个工作空间不是进一步的保密隔离边界。

### 1.2 开始前准备

- 运营方准备企业名称、首位成员账号、数据集、约定的额度与单价；账号必须能正常登录并看到企业管理入口。
- 客户方准备平台访问地址、个人账号、上游模型接口地址、模型标识及必要凭据。上游接口当前需兼容 OpenAI 协议，并使用运营允许域名的 HTTPS 地址。
- 新建或重置成员密码时，密码至少12个字符，包含字母和数字。可点击“生成随机密码”，在保存前妥善记录；旧密码不能查看明文。
- 账号名使用3至50位字母、数字、下划线、点或短横线。成员创建后登录账号固定，编辑资料不会改变登录名。

### 1.3 页面分区

| 分区 | 用途 |
| --- | --- |
| 企业与成员管理 | 运营方管理已开通企业及成员，分配配额，查看指定企业记录 |
| 评测操作记录 | 查看本企业成员操作或 API 访问记录 |
| 需求与交付 | 提交和跟踪评测任务，确认执行、取消、下载报告 |
| 模型服务与版本 | 注册模型服务，维护版本和稳定、灰度路由 |
| 接入方与用量账单 | 创建或撤销接入密钥，查看额度、用量、金额与网关审计 |
| 企业空间与资产 | 新建空间、添加本企业成员、查看共享数据集和授权模型 |

看不到分区或按钮时，先确认账号角色和授权，不要更换对象编号尝试访问。

## 2 运营方操作

### 2.1 开通企业与首位成员

1. 进入“应用服务 → 评测服务 → 企业与成员管理”。
2. 点击“开通企业”，填写企业名称、登录账号和初始密码；也可以生成随机密码。
3. 保存前核对企业、账号及密码。保存后，系统创建企业、首位客户成员及默认工作空间。
4. 在企业列表按名称搜索，确认该企业显示“已启用”，并核对成员数量。
5. 通过约定的安全渠道交付平台地址、账号和初始密码。建议客户首次登录后在个人中心修改密码。

企业开通不代表数据集、模型服务和调用额度已经就绪。继续完成数据交付，并让客户创建接入方后分配额度。运营方不要把自己的管理员账号交给客户共用。

### 2.2 查看和编辑企业

企业列表支持按名称搜索和状态筛选。“成员数”统计未删除成员，包含正常和已停用账号。

1. 找到目标企业，点击“编辑”。
2. 修改企业名称，或选择“启用”“停用”。
3. 保存后刷新并核对列表状态。

停用企业后，成员不能登录使用评测服务，API 网关也会拒绝新请求。重新启用前核对合同、负责人、额度和接入配置。启停企业不等于对已进入执行流程的任务下达取消指令；需要停止任务时应单独处理并核对最终状态。

### 2.3 查看和维护成员

在目标企业行点击“成员与记录”，打开侧边管理面板，选择“企业成员”。这里可查看登录账号、昵称、邮箱、电话和账号状态。

| 操作 | 操作方法 | 结果与注意事项 |
| --- | --- | --- |
| 添加成员 | 点击“添加成员”，填写账号与初始密码后保存 | 企业需处于启用状态；新成员属于当前企业 |
| 编辑资料 | 在成员行点击“编辑”，修改昵称、邮箱或电话 | 登录账号固定，不能在此更名 |
| 停用或启用 | 在“编辑”中切换账号状态并保存 | 停用成员不能登录，该成员创建的 API 密钥也无法正常使用 |
| 重置密码 | 点击“重置密码”，填写或生成新密码并保存 | 旧密码不再用于登录；界面不提供旧密码明文查看 |
| 删除成员 | 点击“删除”，核对提示后确认 | 成员不能登录，相关密钥不可用；历史评测及审计归属保留 |
| 查看成员记录 | 点击“评测记录” | 打开操作记录并自动筛选该成员 |

已删除成员仍可在成员表和记录筛选中出现，便于追溯；其登录账号不能重新注册使用。当前页面没有“恢复已删除成员”按钮，不应将删除当作临时停用。

新密码不要写入评测需求或操作备注。平台只存储密码摘要，不提供密码找回明文；忘记密码应走重置流程。

### 2.4 交付评测数据集

1. 在平台评测数据模块准备数据集，完成当前版本质检与发布，并按平台要求设置共享和授权。
2. 回到企业列表，在目标企业行点击“交付数据集”。也可从“企业空间与资产”点击“交付评测数据集”。
3. 按名称选择已启用企业和已发布且质检通过的数据集，无需手填 ID。
4. 保存后让客户进入“企业空间与资产”，核对共享数据集名称。

交付会复制当前已发布版本及样本到客户企业，保留来源审计和质检信息；不是客户与运营方共享同一个可随时变化的数据集对象。源数据更新后不要假定客户副本自动更新，也不要反复交付制造同名副本；先核对已有交付与版本。

### 2.5 分配接入方额度和单价

客户先在本企业创建接入方。运营方进入“企业与成员管理 → 目标企业 → 成员与记录 → 接入方与配额”，按接入方名称及工作空间识别目标，点击“调整额度”。

| 字段 | 含义 | 填写建议 |
| --- | --- | --- |
| 每日 Token 额度 | 当日可用量上限，含实际使用和在途预占 | 按日常评测规模审批；0会阻止需要预算的调用 |
| 每月 Token 额度 | 当月可用量上限，含实际使用和在途预占 | 根据月度计划设置，不把它理解为每日额度自动累加 |
| 每分钟请求数 | 网关访问频率限制 | 根据调用频率和轮询需要设置 |
| 单价 | 人民币分 / 千 Token | 例如100分表示每千 Token 1元；按已批准价格填写 |

也可从“企业空间与资产 → 为企业接入方分配额度”依次选择企业和接入方。保存后核对接入方列表，要求客户重新打开提交表单查看可用预算。

每日与每月额度按北京时间重置；仍在执行或待核量的预占会影响可用额度。单价在调用创建时冻结，修改价格不代表历史调用会重新按新价计量。页面金额不代表已收款，商业结算按双方约定另行核对。

### 2.6 查询企业和成员操作

在目标企业的“成员与记录 → 操作记录”中查看该企业记录。点击成员行的“评测记录”可直接定位该成员。

“成员操作”覆盖评测提交、确认执行、取消、报告下载及服务、企业、成员管理等已记录动作；“API 访问记录”显示网关请求。选择成员和时间后点击“查询”，或使用“重置”清除筛选。详细说明见第4章。

### 2.7 删除企业

确需结束服务时，在企业列表点击“删除”，核对企业名称和影响后确认。删除会阻止企业成员与 API 继续使用服务，并保留历史资产、计量和审计归属；不是清空全部历史数据。

当前页面不提供已删除企业的恢复入口，也不把已删除企业列入正常企业目录。如需后续查账或留存，应在删除前按组织制度完成资料交接。需要暂时暂停时使用“停用”，不要直接删除。

## 3 客户方操作

### 3.1 首次登录与团队准备

1. 使用运营方交付的地址、个人账号和初始密码登录。
2. 在个人中心核对资料，并按页面要求修改初始密码；个人修改密码与运营重置密码是不同入口。
3. 打开“评测服务”，在页头按名称选择企业工作空间。
4. 进入“企业空间与资产”，确认共享数据集和授权模型；没有可用数据集时联系运营交付。
5. 需要新的工作空间时点击“新建空间”。需要同事加入时点击“添加成员”，填写个人账号及初始密码。

客户侧没有跨企业成员管理入口。本企业成员资料维护、停用、删除和密码重置需要运营方处理；添加成员后不要把个人登录账号转为多人共用账号。

### 3.2 创建接入方并保存密钥

1. 在页头选择工作空间，进入“接入方与用量账单”。
2. 点击“创建接入方”，填写能识别业务用途的名称，例如“模型验证应用”。
3. 保存后，在“请保存接入密钥”弹窗中记录 API Key，并存入组织批准的凭据管理工具。
4. 关闭弹窗后不能再次查看完整密钥，只能看到前缀。密钥丢失时新建接入方并联系运营配置额度，按需要撤销旧密钥。
5. 将企业、工作空间和接入方名称告知运营，申请额度。新接入方默认额度为0，不能自行提高额度。

API Key 用于应用调用评测网关；登录密码用于个人登录；上游 API Key 用于模型接口认证，三者不能混用。密钥撤销后新请求被拒绝，不会恢复显示原密钥。

### 3.3 注册模型服务与版本

1. 进入“模型服务与版本”，点击“注册模型服务”，填写服务名称并保存。
2. 在服务卡片选择一种版本接入方式。
3. 使用“关联已有版本”时，填写服务版本名，按名称选择授权模型和可用的冻结模型版本。没有可用冻结版本的模型不可选。
4. 使用“注册模型接口”时，填写服务版本名，选择允许运营域名的接口地址，填写上游模型标识和所需 API Key；需要时输入同一允许域名下的自定义接口路径。
5. 保存后核对版本标签，并继续配置稳定版本。

上游接口必须使用允许域名的 HTTPS 地址和443端口。地址不能附带用户名、密码、查询串或片段；没有允许的域名时请联系运营。服务版本名与上游模型标识含义不同，不要仅凭示例版本号判断实际上游部署。

### 3.4 配置稳定版本和灰度路由

1. 在目标服务卡片点击“配置路由”。
2. 从已有版本中选择稳定版本。首次接入先只配置稳定版本即可。
3. 确需灰度时选择另一个灰度版本，再设置灰度流量比例；未选灰度版本时比例控件不可用。
4. 保存后核对卡片上的稳定版本、灰度版本与比例。

稳定与灰度版本不能相同。路由影响此后提交的任务，已创建任务保持原版本。切换过稳定版本且存在上一版本时，可点击“回滚”切回上一稳定版本并关闭灰度。配置灰度或回滚不代表质量门禁已经通过，也不是旧流程中的“影子采样”和“转正”。

### 3.5 提交评测需求

点击页头“提交评测需求”，按下表填写。名称、版本和场景尽量从选择项中选取，不需要手动输入内部 ID。

| 字段 | 操作方法 | 核对重点 |
| --- | --- | --- |
| 评测标题 | 输入能识别本次目标的名称 | 方便后续按标题查询 |
| 配置方式 | 选择自动化模式或专家模式 | 自动化直接入队；专家模式还需确认执行 |
| 接入方 | 选择本工作空间有效接入方 | 该接入方需有足够日、月额度 |
| 模型服务 | 选择已配置稳定版本的服务 | 不只确认服务名，还应核对其稳定版本 |
| 共享数据集 | 从本企业已交付数据集中选择 | 样本及参考答案应适合本次评测 |
| Token 预算 | 选择1千、1万、10万、100万档位，或自定义 | 不得超过当前可用额度；额度不足的档位不可选 |
| 评测场景 | 专家模式下从中文选项中选择 | 按业务选择通用问答或其他适用场景 |
| 裁判工具 | 专家模式下选择精确、包含、正则或模糊匹配 | 按参考答案格式选择，不能把规则匹配当作通用专家判断 |
| 定制化需求 | 按需补充文字 | 用于记录需求；不会自动完成任意定制开发或自动审批 |

自动化模式使用标准精确匹配。精确匹配要求答案形式适合对应规则，开放式长文本不宜仅凭规则分数形成完整质量结论。正则等规则还需保证参考答案格式适用。

提交时系统预占预算，结束后按实际用量计量。更换接入方时表单会根据剩余额度调整默认预算。按钮不可用时查看提示，先补齐接入方、已发布模型服务、共享数据集或额度。

### 3.6 专家配置确认与任务跟踪

进入“需求与交付”，按标题搜索，或从提交成员选择项中筛选。列表展示配置模式、状态、进度和实际 / 预占 Token，可独立分页并选择每页条数。

- 专家模式提交后为“待确认配置”，核对需求和配置后点击“确认执行”。此按钮是启动任务，不是专家已经审阅报告的证明。
- 自动化模式提交后直接入队。页面约每15秒更新一次，也可点击“刷新”。
- 草稿、排队、评测中或预算暂停任务可按页面状态“取消”。取消是请求，需继续查看最终状态；已发生的实际用量仍会计量。
- 部分失败或失败时记录调用编号、标题和提示，请运营协助。不要反复提交同一需求制造重复任务。

### 3.7 下载报告与核对用量

有正式报告时，任务行显示“下载报告”，点击保存 JSON 文件。未出现按钮时先检查任务状态和报告是否已生成，不能仅凭进度条判断报告可交付。

在“接入方与用量账单”查看接入方日/月使用量、额度、频率、单价和计量金额。“调用审计与计量明细”显示当前已加载的任务页；完整任务翻页与筛选请回到“需求与交付”。

“已计量”与“已付款”不同；“待核量”说明用量证据尚未完整，不能把0解释为免费或无消耗。金额以人民币显示，上游供应商账单仍需另行核对。

## 4 记录查询与追溯

### 4.1 选择正确入口

| 查询目标 | 入口 |
| --- | --- |
| 运营查看某企业全部记录 | 企业与成员管理 → 目标企业 → 成员与记录 → 操作记录 |
| 运营查看某成员记录 | 目标企业 → 企业成员 → 该成员行的评测记录 |
| 客户查看本企业记录 | 评测服务 → 评测操作记录 |
| 客户查看当前空间网关请求 | 接入方与用量账单 → 网关访问审计 |

主页面的“评测操作记录”默认查询当前登录账号所属企业，不是运营账号所管理的全部企业。运营追踪客户时必须先进入目标企业。

### 4.2 成员操作记录

选择“成员操作”，可按成员、操作类型、开始与结束时间查询。筛选后从第一页展示，记录支持分页；点击“详情”查看完整说明和关联对象编号。

操作时间在此处按北京时间显示。已删除成员仍可作为筛选条件。操作人是实际执行该动作的账号：例如运营为客户调整额度，操作人显示运营账号；不能把该动作算成客户成员本人操作。

关联对象可能是任务、调用、成员、服务或企业，应结合模块和操作类型识别。新补充的操作审计从功能上线后开始记录，旧版本未记录的历史动作不会自动补造。

### 4.3 API 访问记录

切换“API 访问记录”，选择成员和时间，再点击“查询”。查看请求方法、路径、HTTP 状态与接入方名称；详情可展开完整记录。操作类型筛选只用于“成员操作”。

API 请求按密钥创建成员归属，不能由此认定实际调用者一定是该成员本人。幂等重试、参数错误、已知密钥的鉴权失败也可能被记录；一条访问记录不等于新执行了一次评测。未知密钥不能归属企业时，不会出现在某企业的已归属成员记录中。

“接入方与用量账单”的原有网关审计和调用计量时间列标为 UTC；与北京时间记录对照时，北京时间等于 UTC 加8小时。

## 5 应用集成说明

### 5.1 准备请求

页面用户可跳过本章。应用集成人员先完成接入方、额度、模型服务稳定版本和共享数据集准备，再阅读“接入方与用量账单 → API 接入”。页面上的请求示例会展示当前空间对象编号；集成程序使用编号，普通页面通过名称选择。

| 请求头 | 用途 |
| --- | --- |
| X-API-Key | 本企业接入方密钥，不使用个人登录密码或上游模型密钥 |
| Idempotency-Key | 本次业务提交的唯一键；重试同一请求时保留原键 |
| Content-Type | JSON 请求使用 application/json |

### 5.2 提交 查询 下载

| 方法和路径 | 用途 |
| --- | --- |
| GET /api/service-gateway/v1/services | 查询该密钥可用的模型服务 |
| GET /api/service-gateway/v1/usage | 查询额度及使用情况 |
| POST /api/service-gateway/v1/evaluations | 提交评测，参数参考页面 API 接入示例 |
| GET /api/service-gateway/v1/evaluations/{id} | 按返回的调用编号查询状态 |
| GET /api/service-gateway/v1/evaluations/{id}/report | 正式报告就绪后下载 |

同一幂等键和相同请求会返回原调用，不重复预占；同一键用于不同请求会被拒绝。轮询查询也会计入网关请求频率，设置合理间隔，避免每秒密集查询。

API 当前没有专家任务确认执行入口；选择专家模式提交后，由有权成员到页面“确认执行”。不要使用旧的内部委托服务接口替代企业网关，也不要修改数据库中的任务状态。

## 6 状态与常见问题

### 6.1 任务和计量状态

| 状态 | 用户应如何处理 |
| --- | --- |
| 待确认配置 | 专家模式尚未启动，核对后确认执行 |
| 排队中 | 等待执行；异常停留时联系运营检查执行资源 |
| 评测中 | 观察进度和用量，不重复提交 |
| 预算已用尽 | 核对预算与用量，联系运营；本页面没有任意调额续跑按钮 |
| 已完成 | 继续检查正式报告是否就绪和计量状态 |
| 部分失败或失败 | 保留调用编号和错误信息，先处理原因 |
| 已取消 | 核对最终用量；取消不会抹去已发生的消耗 |
| 调用被拒绝 | 检查额度、密钥、服务配置或数据可见范围 |
| 待核量 | 用量证据不完整，不能按0消耗签署结算 |

### 6.2 常见问题处理

| 问题 | 处理方法 |
| --- | --- |
| 运营看不到企业与成员管理 | 请管理员核对 service:list 和 service:admit；记录查询另需 service:records |
| 企业已开通但客户无法登录 | 核对企业、成员是否启用及账号密码；忘记密码由运营重置 |
| 客户看不到其他企业 | 属于企业隔离范围；联系运营核对归属，不修改网址尝试访问 |
| 创建了接入方仍不能提交 | 新接入方额度默认0，请运营分配；同时核对稳定版本和数据集 |
| 模型服务选择项为空 | 先注册版本并配置稳定版本，再打开提交表单 |
| 冻结模型版本不可选 | 请运营或模型负责人核对授权、版本可用状态和冻结接口配置 |
| 数据集列表为空 | 联系运营交付已发布且质检通过的数据集，并确认企业范围 |
| 接口地址被拒绝 | 请运营核对精确域名白名单、HTTPS及443端口，不通过修改地址绕过 |
| 完整密钥不见了 | 密钥只展示一次；新建接入方、申请额度，并按需撤销旧密钥 |
| 找不到旧密码 | 平台不提供旧密码明文；使用重置密码流程 |
| 专家任务一直未启动 | 在需求与交付中找到待确认任务，核对后点击确认执行 |
| 不出现下载报告按钮 | 核对正式报告就绪情况；完成状态不保证文件已生成 |
| 修改单价后旧金额未变 | 调用创建时冻结价格；新价格不自动重算历史调用 |
| API 返回401或403 | 检查密钥撤销、成员或企业状态、账号权限及归属 |
| API 返回429 | 分别核对日/月额度和每分钟请求限制，包括状态查询频率 |
| 记录与任务数量不同 | 操作、访问与任务是不同记录，重试和查询也会形成访问记录 |
| 删除后仍能看到成员 | 属于历史追溯保留；成员已不能登录，不要重复删除 |

### 6.3 联系运营时提供什么

提供企业名称、工作空间、接入方名称、评测标题或调用编号、发生时间和页面错误提示；必要时补充模型服务及版本。不要提供完整登录密码、API Key 或含凭据的请求头截图。运营方将这些信息与成员操作、网关请求和实际任务记录交叉核对后处理。
