## Word 构建

使用 Codex 工作区依赖加载器返回的 Python 执行构建；不需要安装业务运行依赖，也不需要连接数据库。在仓库根目录运行以下命令，将 `<工作区Python>` 替换为实际可执行文件路径。

```text
<工作区Python> docs/user-manual/build_manual.py
<工作区Python> docs/user-manual/build_manual.py --source docs/user-manual/评测服务用户手册_运营方与客户方.md --output docs/user-manual/评测服务用户手册_运营方与客户方_V1.0.docx
```

默认输出总手册V1.2；标题、读者、版本日期及简介从Markdown源文件读取。每份结构报告保存在source-notes下与输出文件同名的structure-check.json文件中。历史版本的结构报告不代表新版本的核验结果。
