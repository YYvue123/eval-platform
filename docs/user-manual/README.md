## Word 构建

使用 Codex 工作区依赖加载器返回的 Python 执行构建；不需要安装业务运行依赖，也不需要连接数据库。在仓库根目录运行以下命令，将 `<工作区Python>` 替换为实际可执行文件路径。

```text
<工作区Python> docs/user-manual/build_manual.py --output docs/user-manual/大模型智能评测平台用户使用手册_V1.9.docx
<工作区Python> docs/user-manual/build_manual.py --source docs/user-manual/评测服务用户手册_运营方与客户方.md --output docs/user-manual/评测服务用户手册_运营方与客户方_V1.1.docx
```

默认构建脚本输出总手册V1.9；标题、读者、版本日期及简介从Markdown源文件读取。每份结构报告保存在source-notes下与输出文件同名的structure-check.json文件中。历史版本的结构报告不代表新版本的核验结果。

本次补充平台模型向企业的显式授权、冻结版本交付、撤销与重新授权操作，更新专项手册第2.5节及总手册第23.4节。两份新Word已按更新正文重建，结构与排版核验状态分别记录。

当前总手册Markdown为V1.9，包含图片、音频、视频的配置与测量范围，以及任务进度、创建时间、创建人和操作说明。多模态详细步骤见[多模态评测操作指南](多模态评测操作指南.md)。历史Word保留作版本参考，不能据其版本号认定已包含新功能。
