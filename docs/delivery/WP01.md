- 改：`deps.py`、`database.py` 迁移与 seed、datasets/tasks/models/prompts/agents/users/roles、permissions/rbac

### 迁移顺序

1. 部署代码 → `init_db` 建表/加列。
2. `seed_tenants_and_backfill`：默认租户、用户挂靠、对象回填；不明归属 `isolated`；内置包 `shared`。
3. 启用强制过滤（已默认开启）。

### API 差异

- 多数写接口忽略客户端 `tenant_id`，写入会话租户。
- 跨租户 get → 404；own 看不到他人 private。
- 禁用用户任意鉴权接口 → 401。
- 新增权限：`dataset:export_sensitive`。

### 权限差异

- RESEARCHER 增加 `dataset:export_sensitive`；VIEWER 不含。
- viewer 角色 data_scope：`shared`。
