# 大模型榜单 V2 交付说明

日期：2026-10-24。本文替代初版演示文档中的界面说明。

### 后续界面修订

分类顺序调整为：全部模型、语言能力、视觉语言、视频模型、语音模型、K12 学科、金融专项、安全可信。“安全可信”已增量新增三个模拟模型、六维能力（有害内容防护、越狱防护、隐私保护、事实可靠性、偏见与公平、合规拒答）和四期趋势；沿用模拟数据隔离及不可正式发布规则。原有三个模拟分类载荷保留，分类数量由数据库动态读取。

被测模型的基础信息增加开源/闭源选择，沿用 ModelMeta.source_type，模型列表、详情和榜单读取同一字段；兼容已有 open/open_source、closed/closed_source 值，历史自研/微调来源不自动推断开闭源。列表 API 同时返回元信息，避免编辑时丢失字段。榜单已修复“全部模型”按钮的空字符串 disabled 问题，并保留全部分类的地址状态；删除右上箭头字符；内置评分器名称与内置题集名称改为中文显示。任务列表、任务详情返回并显示被测模型、数据集和评测工具名称，关联名称遵守对象可见范围。

按用户随后允许造假数据的要求，通过受 leaderboard:edit 控制的 `/api/leaderboard/demo/seed` 在 staging 新增三份独立模拟展示载荷（图像、视频、语音，各三个虚构模型、六维分数、四期趋势）。接口幂等，不覆写既有载荷，不写 eval_tasks/eval_results，不产生正式通过或发布记录。页面顶部“模拟演示”开关显示醒目提示，并关闭正式发布/计价管理；真实榜单仍默认展示。演示来源为专用表 `leaderboard_demo_payloads`，模拟数据不会作为正式榜单成绩。

## 展示和交互

参考 FlagEval 的分类入口、紧凑筛选区、固定模型列、多指标排名和即时对比，重新组织页面。四类榜单直接展示在主导航：综合得分、单项 Top10、专项、性价比。支持行业、场景、模型、版本、评测起止时间及指标筛选，表格、模型卡片、跨套件能力档案、CSV 导出和来源证据抽屉。

对比区支持最多五个配置，采用圆形雷达、条形图、能力热力图、历史曲线和质量时延散点图。图例可点击隐藏，颜色保持对应，支持悬停、历史缩放、放大和 PNG 保存。雷达仅展示共同完整维度，使用固定 0–1 量尺，缺测不补零。

## 需求覆盖

| 要求 | 实现和边界 |
| --- | --- |
| 综合分与后台权重 | 按同一协议的题目标签维度配置非负权重，实时榜重算；发布快照不随权重改变 |
| 单项榜 | 指标选择、按单项分排名、最多 Top10；实测配置不足十个时如实显示 |
| 专项榜 | 仅纳入行业、场景、安全等专项任务，不将普通任务作为专项占位 |
| 性价比榜 | 实测用量乘以明确配置单价，按综合原始分/每样本估算费用排序；缺单价或零费用不排名 |
| 历史期数 | 管理员发布冻结筛选范围、模型版本、权重和汇总分，期数下拉回看 |
| 发布与撤回 | 默认私有；可明确生成免登录汇总链接；撤回后接口返回 410，客户端定期重新验证 |
| 异常复核 | 来源任务待复核时暂停入榜，关联已发布快照自动撤回；恢复结果不自动重新发布 |
| 权限与审计 | 查看、编辑、发布、撤回、复核分权；后端租户/对象范围校验；写操作记录审计 |
| 语言/K12/金融 | 已通过真实模型调用增加演示题集和正式执行结果；均为小样本示例 |
| 图像/视频/语音 | 保留分类入口，暂无正式结果时禁用，不以文本结果冒充多模态能力 |

不同数据集版本、评分器、工具版本及评测协议分别排名。百分制只是已知 0–1 量尺的显示换算，不代表不同工具分数已经可互比。未知量尺只展示原始分，不授予综合排名。开放文本的 fuzzy 分表示词面相似度，不等于通用能力准确率。

## staging 增量数据

页面：`http://127.0.0.1:5173/leaderboard`，API：`:8000`，使用 `.env` 的 staging 数据库。`:5180` 仍是早期独立演示库。

本轮通过平台数据集和任务 API 新增三类题集、13 次真实评测、144 条逐样本结果：六维语言两轮、K12 六学科、金融四维，以及一项人工复核流程示例。三个配置使用同一已配置底层模型，名称是接入别名，页面标明演示身份，不代表三款独立模型。任务 #32 为人工复核操作示例，不声称模型已被证实异常。

新增六个私有发布期数，覆盖语言两期、单项、性价比、K12 与金融。没有自动对外开放客户演示链接。

执行入口：`backend/scripts/populate_leaderboard_v2.py`。脚本先备份，再经正式 API 增量导入、质检、发布题集、创建和执行任务；不直接写评分事实。成功任务可复用。原有数据集、版本、样本、任务和结果逐行哈希核对保持不变，见 `leaderboard-v2-staging-evidence.json`。

本轮任务数由 19 增至 32，结果数由 122 增至 266；未删除原记录。备份路径保存在上述证据文件中。数据库含接入凭证，不应作为客户交付附件。

## 验证

后端回归使用 `tests/isolated_env.py`；浏览器测试使用 staging 的 SQLite backup 隔离副本 `backend/tests/_isolated/leaderboard-ui-v2.db`，不对业务库执行测试。后端覆盖权重、租户隔离、发布权限、不可变快照、公开字段脱敏、复核自动撤回及恢复不重发；图表单测覆盖缺值、比例显示与稳定配色。浏览器入口为 `frontend/e2e/leaderboard-v2.spec.mjs`，截图保存于 `leaderboard-v2-screenshots/`。

验证结果：后端共 15 项通过、1 项因无任务跳过，包含新增 Top10 截断与模型筛选用例；前端图表 5 项通过；浏览器 2 项通过，包含五图切换、图例、图片/CSV、卡片、期数冻结、管理菜单、移动端及匿名公开后撤回流程；前端生产构建和 64 项权限采集通过。
