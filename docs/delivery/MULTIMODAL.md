## 已实现

- 数据集 JSON/JSONL 的 `media` 数组携带内嵌 PNG/JPEG/WebP，每题最多 8 张，每张最多 10MB、2500 万像素。校验实际格式、SHA256 和区域坐标，禁止可变外链。页面样本展开栏可添加图片，操作创建新版本并重新要求质检发布。
- 图片字节、参考证据、区域和安全评分准则纳入版本内容校验；修订不会修改旧版本。
- 模型 `support_modal` 可填写 `text,image`，或 `{"input":["text","image"],"output":["text"]}`。输入与输出能力随访问配置冻结；创建任务及实际调用均检查，不支持的组合拒绝执行。
- 被测模型首轮、追问、独立情境对照及模型裁判均接收原图，使用 OpenAI 兼容 `image_url` 内容块。未以 OCR/文字描述替代图片。
- 每条结果保存原图、SHA256、区域和处理方式。任务详情、安全结果、专家复核和人工金标窗口可查看图片，报告 JSON 保留完整证据，HTML 显示原图与分模态统计。
- 安全结论和人工金标校准按输入模态统计；无实测的模态和维度保持缺测。原始自动评分不被专家复核或金标覆盖。
- 榜单移除模拟开关和模拟 API；旧 `demo=1` 链接进入真实榜单。视觉分类依据已完成结果中的实际输入模态，不依据模型能力标签推测。未执行图片的历史文本任务不算视觉评测。

复用 `dataset:edit`、`task:create/run/view`、`safety:create/view/edit` 和 `leaderboard:view` 权限，没有新增权限码。权限采集通过，共 69 个权限码。

## 样本格式

```json
{
  "input": "图片里的方块是什么颜色？",
  "reference": "red",
  "media": [{
    "modality": "image",
    "name": "sample.png",
    "data_url": "data:image/png;base64,<图片字节>",
    "regions": [{"label": "目标方块", "box": [0.1, 0.1, 0.8, 0.8]}]
  }]
}
```

`box` 为归一化 `[x1,y1,x2,y2]`。安全样本另外提供既有 `safety.dimension/rubric/evidence` 和行为、答案锚点；这些标注与图片一起冻结。`sha256` 可省略，导入时计算；如提供则必须与图片一致。多模态裁判也必须声明图片输入能力。
