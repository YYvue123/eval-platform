# 安全可信工作台

更新：2026-10-25。安全评测对象是被测模型的生成内容及行为，平台自身的权限、审计和运维检查不替代模型安全测评。

## 架构与原有差距

执行仍由任务管理和 TaskService 负责。安全菜单管理专项基准、配置、证据、结果热力图、专家复核及校准；从安全菜单创建的任务仍是 EvalTask，task_type=security。

原实现已有风险、标识、价值对齐和幻觉规则裁判，但任务执行未向裁判传递样本证据元数据；对齐主要检查立场关键词，幻觉只检查少量对象和关系，难度自适应仅为风险夹具提示；复核状态保存在内存。不能据此认定完整满足专项指标。

## 本次实现

- safety-protocol-v2 统一使用题目的 safety 元数据，覆盖五类内容风险、文本显式标识和输出JSON元数据、价值对齐四维、幻觉六类，共17个指标。
- 安全基准复用 Dataset、DatasetVersion、DatasetItem 的导入、质检和发布。每题保存评分准则、证据、立场、答案锚点、预期行为及分支追问。开发模板为17道人工可核验的小样本题，不是外部行业题库。
- 任务冻结场景、权重、固定/探索用途、多轮上限、规则融合权重和裁判模型版本；全部进入比较组条件。普通任务历史比较组算法保持兼容。
- 复用统一模型接入，使用真实 messages 历史进行多轮追问。前轮得分决定easy/hard分支，最多三轮。保存每轮问题、输出、难度、规则检查、裁判理由、融合参数和分数。
- 可选模型裁判，仅接受合法JSON评分，缺理由、越界分数或解析失败记为评分失败，不当作通过。调用记录、Token和时延保留。规则与模型意见冲突或裁判要求人工介入时进入待复核状态。
- 当前应用数据库增加 safety_records 表，追加保存复核和校准记录。复核绑定结果hash，重试后旧意见不自动套用；原始评分保留。校准对照人工独立填写的真实结果金标，返回一致率和绝对误差，并明确样本范围。
- 安全榜继续使用真实任务榜单，提供合格率、主客观题合格率、拒答率和17维得分。探索、试跑、模拟、不完整实测、评分错误、待复核和驳回结果不进入可比榜。
- 报告JSON包含安全配置、完整轮次和评分证据，Markdown增加安全专项证据段；任务详情可跳转到对应安全结论。

## 接口与授权

| 接口 | 权限 | 用途 |
| --- | --- | --- |
| GET /api/safety/workbench | safety:view | 可见基准与安全任务 |
| GET /api/safety/benchmark-template | safety:view | 开发基准模板 |
| POST /api/tasks，携带safety_config | task:create及safety:create | 创建统一安全任务 |
| GET /api/safety/assessments/{id} | safety:view | 同一任务的安全结论 |
| POST /api/safety/assessments/{id}/reviews | safety:review | 追加专家意见 |
| POST /api/safety/assessments/{id}/calibrations | safety:edit | 保存真实结果与人工金标对照 |
| GET /api/safety/assessments/{id}/records | safety:view | 复核和校准历史 |

研究员可查看、配置、复核和校准；只读角色只查看。任务、数据集及模型仍检查租户/对象权限，模型裁判仍需模型ACL。基准创建、导入、质检、发布和执行还需各模块原有权限。

## 可重复的真实开发演示

使用当前数据库及.env中的模型连接，经认证API创建数据、质检发布、创建及执行任务。不得运行隔离回归脚本指向业务库，不直接插入或修改评分、任务状态和调度字段。

```powershell
cd backend
.venv/Scripts/python.exe scripts/demo_safety_development.py --stage prepare
.venv/Scripts/python.exe scripts/demo_safety_development.py --stage start --task-id <任务ID>
.venv/Scripts/python.exe scripts/demo_safety_development.py --stage collect
```

可用--rule-only创建独立规则协议的真实任务；它与规则加模型裁判的结果属于不同比较组，不以规则分数冒充模型裁判结果。专家复核和人工校准必须由真实操作者独立完成，演示脚本不自动批准。真实结果和失败记录见 safety-development-evidence-2026-10-25.json。

## 仍需建设的正式验收范围

本次补齐工作流和指标承载，不代表大规模安全有效性验收完成。仍需领域专家维护并验证足量、代表性、跨文化的动态基准与独立金标；对抗题强度和难度阶梯也需经验校准。关键词规则存在误报漏报，模型裁判存在偏差和同源自评风险。

标识检查当前针对文本显式标识和模型实际输出JSON元数据；没有测量图像、音频、视频的隐式水印嵌入/提取、擦除及压缩鲁棒性，不能声称已完成全模态标识合规认证。六类幻觉目前为给定证据下的受控测试；开放世界事实核验、外部检索证据时效、专家标注和生产压测需另行验收。

| #43 | deepseek-flash | 规则与模型裁判各50% | 17 | 0.9537 | 3 | 排除 |

隔离回归组合执行41项，40项通过、1项因隔离库没有可用报告任务而跳过；补充后的工作台8项回归全部通过，包含新增任务API冻结及跨数据版本拒绝。前端构建、权限采集和diff空白检查通过。浏览器实际确认17项配置权重、任务#45的17维热力图和17条样本，以及真实安全榜两个模型、主客观题合格率、总拒答率和图表。

## 页面交互修订

安全页使用任务管理相同的全局标题、说明、卡片、表格和表单样式，去掉英文抬头及无交互的四分类卡片。分类改用于模板筛选和指标分组。

指标权重改为百分比，预设通过整数分配余数保证合计恰好100%，提交前校验总和。支持按比例归一化；所选基准只显示对应指标。规则与模型裁判权重也以百分比显示，提交时转换到既有协议的比例值，不修改历史任务配置或评分。

模板目录增加综合、内容风险、标识、价值对齐、事实一致性、多轮对抗六种可选模板；专项模板按真实题目过滤，多轮模板增加第三轮分支。页面显示用途和题目预览，去掉开发名称及原来源提示；题目、证据和高级JSON仍可查看编辑。

复核结论、评分状态和记录历史使用中文。设置金标改为弹窗独立输入百分比分数，确认后显示已设置状态和清单，保存校准才提交API；刷新保留证据未变的草稿，结果变化或切换任务后清除。浏览器验证仅使用前端草稿，未向业务库提交人工金标或复核结论。

修订验证：百分比计算与中文映射3项前端单元测试通过；模板覆盖及工作台9项隔离回归通过；前端构建与权限采集通过。浏览器确认六张模板卡片、金标空白输入弹窗、确认反馈和刷新保留。用户手册第21章同步更新。
