## 决策备忘（原计划 ADR）

- **spec_version / profile**：资源 manifest 可有独立 `spec_version`；信封统一使用 `profile=platform-v0.6.1/envelope-1.3`，不与资源 SemVer 混用。
- **兼容**：旧客户端可读 `header.status`；新契约以 `body.status` + `body.result` 为准。

## 未做什么 / 未验证

- 完整 async/stream 任务子系统、Redis 令牌桶、SSE 注册准入状态机（计划明确本会话不做完）。
- Mock HTTP 外部裁判全链路自动化用例未补；HTTP 路径靠 adapter 实现与 builtin e2e 覆盖。
- 附录 A 全量 JSON Schema 正反例未逐文件挂载；请求校验为 protocol 内字段级校验。
- 非 builtin 资源的对象可见性矩阵未单独成套测试（builtin 全租户只读）。

- invoke 响应：`body.status` / `body.result`；`auth.caller_id` 非空。
- 客户端传入的 `tenant_id` 不采信，以 ActorContext 为准。
