### API / 行为差异

- PATCH 数据集条目返回新版本上的条目；旧 `version_id` 内容不变。
- 未质检 `publish` → 400。
- 正式 `POST /tasks` 对 draft/unchecked 数据集 → 400；`trial_run` 仍可。
- 改模型 `api_url` 等 → 新 `model_version` + 新 AccessConfig；激活旧版本恢复旧 URL。

## 回滚

1. 条目修订回退为原位修改会破坏已 pin 任务复现——禁止生产回滚该行为。
2. 正式任务门禁可临时放宽需产品批准；勿默许 draft 进正式跑。
3. AccessConfig 已写入的历史行应保留；勿用 live 覆盖旧 version 行。
