# 评测助手交互与长任务跟踪

更新日期：2026-10-25。对应用户手册V1.7。

## 回复来源标识

助手回复旁标示主Agent或具体子Agent。优先使用delegate:角色与消息中的角色、名称快照识别，兼容历史上role=main的子Agent回复；旧消息从角色目录补充名称。主Agent汇总保留主Agent标识，用户和系统消息不伪装成模型回复。新消息保存agent_name，角色改名不改写历史名称。真实会话20及17已核对主Agent、规划角色、监控、报告审校和自定义顾问；21项隔离回归、名称快照专项和前端构建通过。

## 对话确认与阅读主题增补

对话默认至少720px高，专注阅读隐藏会话侧栏。能力选择增加独立边框、选中底色和间距，设置提示词与模型表单间距26px。修复Vue作用域暗黑选择器丢失目标的问题，并对榜单图表、坐标、雷达背景、提示框和图片导出适配主题。

聊天明确输入“确认执行”等受支持短句时，前端调用原confirm受控入口，携带当前canonical_hash、原始用户消息和幂等标识。后端校验明确指令及版本，仍要求agent:confirm；计划未就绪、分析未完成和校验失败均阻止执行。用户消息与授权hash落库，后续使用原TaskService、审批审计、入队和跟踪流程。模糊同意、引述或附带额外修改的句子不触发自动确认，先由助手分析再重新明确确认。

propose_resources支持试跑模式和非负Token预算，更新计划使旧审批失效；已有任务时禁止再改计划。该功能不赋予模型自行审批的权限。

## 使用入口

左侧为带颜色状态的会话列表。中央分为对话与计划、执行明细、报告与经验，配置集中在助手设置抽屉。保留计划证据、必要的资源与预算配置，删除高级区重复启动、恢复和调试入口。

新建评测清空目标、补充消息、预算、能力选择与上一会话状态。后续消息发送时立即显示本地用户消息及三点等待动画，成功后按client_message_id与落库消息去重。失败保留输入证据并显示错误。首条需求不再因自动创建规划Run重复保存；旧会话的同需求规划副本仅在展示时过滤，审计记录保留。

Markdown使用markdown-it与DOMPurify，支持表格、代码块、嵌套列表、引用，禁止原始HTML执行并清理危险链接。“继续分析当前计划”沿用保存的目标分析未完成事项，不再次提交相同原文，也不自动执行评测。

## 真实能力边界

- 试跑模式与旧试用模式是同一评测开关；用于联调链路，放宽部分正式门禁，不自动抽样、不免除真实模型费用、不作为正式准入。工具底座的单工具试用另属独立功能。
- 实时执行动态通过带Authorization的fetch SSE接收已提交事件；不是模型逐字Token输出。按after_seq重放，连接中断后自动接续，原有轮询作为后备。代理应关闭SSE缓存并允许长连接。
- 关键操作人工确认不可关闭。创建执行、配置变化后的重新审批、恢复补测及报告发布沿用业务门禁；没有任意节点中途接管能力。旧human_in_the_loop参数不能关闭这些门禁。
- 模型决策3/10指本Run主Agent已调用模型3次、上限10次，不是聊天轮数或样本数。子Agent另有决策次数和用量。每轮执行明细的选择器则切换历史Run。

## 长任务与停止继续

后台Agent worker读取持久化TaskEvent游标和任务快照，通过轮询发现变化，不依赖浏览器在线，也不是消息队列订阅。任务状态变化、进度跨10%区间、失败数变化、报告就绪触发跟进；无变化5分钟后记录心跳。记录提交后SSE推送给页面。专项调用按事实签名去重；心跳不反复消耗同一专项模型。服务停机无法产生新消息，恢复后读取最新状态继续。

POST /api/agents/sessions/{sid}/stop需要agent:invoke及对象访问权限。停止助手分析与跟踪，执行节点间生效，已发出的请求仍可能计费；不会取消关联Task。用户需到任务详情取消评测。

POST /api/agents/sessions/{sid}/continue同样需要agent:invoke。等待Run可重新入队；终止Run新建一轮分析或跟踪，保留上下文与关联任务，不重复创建Task。预算暂停要求新限额高于原限额及已用量，更新计划并使旧审批失效。任务失败本身仍须诊断并另行确认恢复或补测。

停止与继续均写审计。沿用既有agent权限，无新增权限代码；前端按钮具有权限条件。
